# ⚗️ Chemistry Quiz (원소 퀴즈)

주기율표 원소의 기호·이름·원자번호를 맞히는 웹게임. 빌드 없이 정적 파일만으로 동작합니다.

- 3가지 모드: 기호→이름 / 이름→기호 / 원자번호→이름
- 3가지 난이도, 10문제, 문제당 10초
- 남은 시간 + 연속 정답 보너스, 최고 점수는 브라우저에 저장

## 로컬 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `chemistry-quiz`)
2. 이 폴더 내용을 push
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 저장
4. `https://<사용자명>.github.io/chemistry-quiz/` 에서 접속
